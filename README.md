# WEBFLUX — сайт для GitHub Pages

## 1. Загрузка на GitHub Pages
1. Создайте репозиторий (например, `webflux`) и загрузите в него **содержимое** этой папки (файл `index.html` должен лежать в корне).
2. Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`.
3. Сайт откроется по адресу `https://ВАШ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## 2. Укажите свой адрес сайта (обязательно для SEO)
В файлах уже указан адрес `https://tonytest180.github.io/webflux/`. Если имя пользователя или репозиторий у вас другие, замените адрес одной командой: `python set-site-url.py https://ВАШ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`
(или найдите и замените адрес вручную в `*.html`, `sitemap.xml`, `robots.txt`).
Если подключите свой домен, положите в корень файл `CNAME` с этим доменом и запустите скрипт с адресом `https://ваш-домен.ru/`.

## 3. Google Search Console
1. Добавьте ресурс «Префикс URL» с адресом вашего сайта.
2. Выберите подтверждение «Тег HTML», скопируйте значение `content`.
3. В `index.html` найдите строку `<!-- <meta name="google-site-verification" ...> -->`, раскомментируйте её и вставьте код. Загрузите файл на GitHub и нажмите «Подтвердить».
4. Sitemaps → добавьте `sitemap.xml`.
Другой способ: загрузите в корень HTML-файл `googleXXXX.html`, который выдаст Google.

## 4. Яндекс Вебмастер
1. Добавьте сайт, выберите подтверждение «Метатег».
2. В `index.html` раскомментируйте `<meta name="yandex-verification" ...>` и вставьте код.
3. Подтвердите права, затем в разделе «Индексирование → Файлы Sitemap» добавьте `sitemap.xml`.
Другой способ: загрузите в корень файл `yandex_XXXX.html` из Вебмастера.

Строки для кодов есть на всех четырёх страницах, достаточно заполнить `index.html`.

## 5. Структура
- `index.html`, `portfolio/`, `services/`, `contacts/` — отдельные страницы с собственными title, description, canonical, Open Graph и разметкой schema.org.
- `404.html` — страница ошибки (не индексируется), `robots.txt`, `sitemap.xml`, `site.webmanifest`.
- `assets/` — стили, скрипт, изображения (WebP для превью и JPG для просмотра на весь экран), иконки, `og-image.jpg` для превью ссылок.
